# Tlipoca

这是一个基于 Forge 1.21.10 / Java 21 的《犹格索托斯的庭院》同人 Minecraft 模组。

## 模组介绍

在Minecraft 世界 重建庭院。

当前玩法围绕冒险战斗、庭院据点、SAN 与神谕风险构筑展开。庭院不是重经营系统，而是玩家用于准备、炼金、恢复、查看记录和接取收魂悬赏的异界基地。

## 已有内容

- SAN 系统、HUD 与自然衰减/回复
- 6 个神谕与神谕典藏 GUI
- 占卜台
- 庭院锚点
- 庭院炼金台与供物台
- 庭院账簿 GUI
- 悬赏板与悬赏单系统

## 开发环境

- Minecraft 1.21.10
- Forge 60.1.0
- Java 21
- Mod ID: `tlipoca`
- 主包名：`io.tlipoca.mod`

## 构建

```powershell
.\gradlew.bat clean compileJava --console=plain
.\gradlew.bat build
```
